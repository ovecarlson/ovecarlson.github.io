A R T O M A T I C

This work called ARTOMATIC consists of a custom-developed generative image system that continuously creates and displays new images in real time. Using elementary geometric forms such as lines, circles, and rectangles, each image emerges through a combination of predefined rules, random variation and relationships between color, transparency, scale and layered structures. Each image exists only temporarily before being replaced by a new one. The process can continue indefinitely, generating a virtually unlimited number of unique compositions.

The probability of the same image appearing twice is negligible. The artwork is therefore not a collection of images but a system for producing images.

The artistic act resides in the design of the rules, parameters, and visual language that govern the process. What appears on the screen is a continuously evolving manifestation of this underlying system. By combining control and unpredictability, the work explores questions of authorship, variation, time and perception. Viewers never encounter the same artwork twice, but rather a fleeting moment within a potentially infinite visual continuum.

ARTOMATIC can be implemented on monitors of various sizes and layouts. Each installation has an unique set of rules. The appearance and viewing time of the generated pictures can be adapted to serve different purposes and environments.
